# CS320SoftwareTestQA

How can I ensure that my code, program, or software is functional and secure?
I can ensure my software is functional by following requirements and using unit tests to identify errors. I can improve security by validating inputs, following secure coding practices, and regularly reviewing my code.

How do I interpret user needs and incorporate them into a program?
I interpret user needs by reviewing the requirements and turning them into program features. I then test those features to make sure the software meets the user's expectations.

How do I approach designing software?
I start by understanding the requirements and breaking the program into smaller components. I develop and test each part to create software that is organized, reliable, and easier to maintain.
